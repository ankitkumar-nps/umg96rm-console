Sign in, pick a gateway, then run a command.

Suggested order on a fresh install:
  1  loopback      jumper D0-D1, module unplugged   -> proves UART + pins + chip
  2  sniff 15      listens only                     -> silence vs wrong baud vs another master
  3  scan          baud x framing x slave id        -> an exception counts as success
  4  read 19006 6  the three L-L voltages           -> look for 451 / 449 / 447
  5  poll 1        start publishing

scan can take ~80 s and sniff runs for its full window — the RPC reply arrives when the sweep finishes. The device stays responsive throughout.
